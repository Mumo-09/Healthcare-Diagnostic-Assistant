# Healthcare Diagnostic Assistant

An AI-powered healthcare diagnostic prototype that combines multiple artificial intelligence techniques to analyse reported symptoms, estimate urgency, and provide preliminary recommendations.

## Overview

The Healthcare Diagnostic Assistant demonstrates how different AI approaches can work together in a healthcare-related application. Users enter patient information, select symptoms, and receive an analysis generated by the system's AI modules.

The application includes a Streamlit interface for patient information and analysis results.

**Disclaimer:** This project is an educational prototype. It is not clinically validated and must not be used to diagnose or treat medical conditions or replace professional healthcare advice.

## Features

* Patient information and symptom collection
* Knowledge-based reasoning using medical rules
* Bayesian diagnostic inference
* Machine learning classification
* Neural network-based analysis
* Fuzzy logic for severity assessment
* Treatment planning and recommendations
* Streamlit-based interactive interface
* Individual AI module results for inspection

## AI Modules

| Module            | Purpose                                                          |
| ----------------- | ---------------------------------------------------------------- |
| Knowledge Base    | Applies predefined facts and rules to infer possible conclusions |
| Bayesian Network  | Estimates diagnostic possibilities using probabilistic reasoning |
| Machine Learning  | Performs classification using the implemented model              |
| Neural Network    | Demonstrates neural network-based analysis                       |
| Fuzzy Logic       | Assesses severity using fuzzy rules                              |
| Treatment Planner | Generates proposed next actions                                  |
| Intelligent Agent | Coordinates the AI modules and combines their outputs            |

The results depend on the implemented rules, model configuration, and available data. Agreement between modules does not guarantee medical accuracy.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Mumo-09/Healthcare-Diagnostic-Assistant.git
cd Healthcare-Diagnostic-Assistant
```

### 2. Create a virtual environment

**Windows:**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

If a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

Otherwise, install the packages required by the application and its modules.

### 4. Run the application

```bash
streamlit run streamlit_app.py
```

Streamlit will provide a local URL to open the application in your browser.

## How to Use

1. Launch the Streamlit application.
2. Enter the patient information requested by the interface.
3. Select the reported symptoms or enter additional symptoms.
4. Click **Analyze Symptoms**.
5. Review the generated analysis, urgency estimate, recommendations, and individual AI module results.

Symptoms that are not covered by the system's rules or models may not be interpreted correctly.
